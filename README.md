# Registro de triángulos con ASP.NET Core y Neon

Reporte de Ayotitla Lazcano Jose Armando, grupo 7E. Sitio estático con 26 capturas y referencias oficiales. No ejecuta la aplicación C# ni se conecta a Neon.

## Abrir y revisar
Abre index.html en tu navegador. Conserva la carpeta img junto al archivo. Puedes pulsar una captura para verla a tamaño completo. Para imprimir desde el menú del navegador, selecciona A4 y activa los encabezados y pies de página del navegador. Comprueba los números en la vista previa: no se ha verificado la impresión en un navegador durante esta revisión.

## Estructura
- index.html: reporte completo y estilos integrados.
- img/: 26 capturas PNG; nombres sin espacios.
- .nojekyll: publicación estática sin procesamiento Jekyll.
- README.md: estas instrucciones.

## Publicar en GitHub Pages
1. Si usarás un repositorio existente, revisa su estructura antes de subir archivos. No sobrescribas un sitio previo.
2. Para uno nuevo, crea un repositorio público llamado reporte-triangulo-poo7e.
3. Extrae el ZIP. Sube index.html, img y README.md a la raíz del repositorio. No subas el ZIP como sustituto de los archivos.
4. Guarda la carga con Commit changes.
5. Ve a Settings > Pages. En Build and deployment selecciona Deploy from a branch.
6. Selecciona la rama main y la carpeta /(root); pulsa Save.
7. Espera a que termine el despliegue. El enlace aparece en Settings > Pages.
8. Abre el enlace, prueba el índice y las 26 imágenes en una ventana privada y desde un móvil. El formato usual es https://USUARIO.github.io/reporte-triangulo-poo7e/.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Evidencias y privacidad
Solo se incluyeron las capturas del ZIP. La contraseña visible en la captura de appsettings y su miniatura fueron cubiertas de forma opaca, manteniendo tamaño y resto de los píxeles. La captura Connect ya traía la contraseña enmascarada. No se incluye ningún appsettings.json ni proyecto ejecutable ni capturas originales con la contraseña visible.

El contenido aclara que faltan las capturas de pruebas inválidas/duplicadas, la configuración final corregida, la compilación final, y las consultas SQL de los otros dos registros. No se agregó /triangulos.

## Lista de cotejo y diseño
Portada (2 %), índice (3 %), introducción (5 %), marco teórico con citas APA (10 %), procedimiento con capturas y explicaciones (50 %), ortografía (10 %), justificado y paginado (5 %), conclusión (5 %) y referencias APA (10 %). Son criterios, no calificaciones.

El HTML es continuo y responsive. No usa páginas A4 ni alturas fijas en pantalla. El objetivo se integra en la introducción; herramientas, comandos y pruebas se incluyen dentro del procedimiento. En celular el texto se alinea a la izquierda para evitar espacios excesivos y las tablas tienen desplazamiento horizontal.
